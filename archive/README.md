# Original submission archive

The uploaded ZIP is preserved byte-for-byte as ordered parts. Run `python3 scripts/restore_assets.py` from the repository root to reconstruct and verify `archive/original-submission.zip`, then restore project assets and the presentation video. On Windows, use `py scripts/restore_assets.py` with Python 3.8 or newer.

The archive retains the submitted source, media and historical generated files. The main repository source excludes caches and old compiled binaries. Restoration does not execute or install those binaries.
